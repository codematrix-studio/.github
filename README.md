# Общая документация CodeMatrix

Репозиторий содержит материалы, общие для CodeMatrix и не привязанные к одному техническому каркасу или продукту.

## Разделы

- [Стратегия](strategy/README.md) — выбранные направления развития и планы.
- [Исследования](research/README.md) — рынок, технологии и сторонние проекты.
- [Идеи](ideas/README.md) — технические возможности, ещё не ставшие частью продукта.
- [Инженерные материалы](engineering/README.md) — общие стандарты и справочники.
- [Профиль](profile/README.md) — публичное описание CodeMatrix.

## Принципы

1. Здесь хранятся общие материалы, применимые к нескольким проектам.
2. Реализации, тесты и инструкции по сборке Bitrix-сайта остаются в [bitrix-quickstart](https://github.com/codematrix-studio/bitrix-quickstart).
3. Описание идеи не означает обязательства её реализовать.
4. Для сторонних проектов фиксируются оригинальный источник, назначение, ограничения и безопасный способ изучения.
5. Устаревшие сведения пересматриваются и помечаются.

CodeMatrix — независимая разработка одного специалиста; документация не предполагает наличие отдельной команды.
