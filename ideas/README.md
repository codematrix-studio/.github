# Идеи и технический backlog

Здесь фиксируются идеи, которые могут стать компонентами, библиотеками, модулями или улучшениями продуктов. Запись идеи не означает обязательства реализовать её.

## Категории

- [1С-Битрикс](bitrix/README.md)
- [Frontend и JavaScript](frontend/README.md)

Для каждой идеи желательно указывать источник, суть, пользу, ограничения, статус и ссылку на реализацию, если она появилась. Исходный код не переносится автоматически: сначала проверяются актуальность API, лицензия, безопасность и реальная потребность.
